# 交付契约与阶段门禁

## 交付契约

完整功能开始前，在会话中维护一份简短的交付契约。除非用户明确要求，不必把它写入目标仓库。

| 项目 | 内容 |
| --- | --- |
| 业务目标 | 用户完成什么操作，系统产生什么结果 |
| 范围 | 本次包含和明确不包含的对象、端和环境 |
| 模型变化 | 新增或修改的 `BusinessObject`、`Model`、`Property`、`Index`、`RelatedBO` |
| 后端变化 | BO、规则、Logic、Repository、REST、配置、初始化和测试 |
| 前端变化 | `api`、`borep`、`bsapp`、`bsui/c`、注册和语言资源 |
| 数据库变化 | 表、字段、主键、索引、BO 元数据、初始化 SQL 和初始业务数据 |
| 验收条件 | 可观察、可判断通过或失败的业务行为 |
| 环境条件 | 构建工具、数据库类型、连接配置、测试数据和外部依赖 |

推断内容要标记依据。对象类型、主子键、状态语义、目标数据库和删除性操作不能仅凭命名猜测。

## 阶段交接

### 模型阶段输出

- 最终 `Domain` XML 路径；
- 对象、模型、字段、映射、索引和关系清单；
- 相比基线的真实模型增量；
- 尚未实现的枚举或待确认语义。

### 代码生成阶段输出

- 生成输入和候选根目录；
- 新增、语义合并、跳过的文件；
- 保留的手工代码；
- 模板遗留项与需要后端或前端接手的工作。

### 开发阶段输出

- 已实现的后端和前端契约；
- 注册、资源与测试变更；
- 构建命令和结果；
- 需要数据库支持的模型或初始化内容。

### 数据库阶段输出

- 命令模式、数据库类型和目标环境标识；
- 应用的数据结构 XML、模块 JAR 或 SQL 编排文件；
- 成功、跳过和失败的动作；
- 后置结构核验结果，不记录凭据。

### 验收阶段输出

- 每项验收条件的证据与结论；
- 未运行项、原因和完成它所需的条件；
- 需要返回修复的责任阶段。

## 门禁判定

| 门禁 | 进入条件 | 失败时返回 |
| --- | --- | --- |
| 模型确认 | XML 完整且关系、映射、类型明确 | 业务对象建模 |
| 生成合并 | 候选输出有效且只合并真实增量 | 代码生成或模型阶段 |
| 构建通过 | Java 与 TypeScript 受影响单元通过 | 后端或前端开发 |
| 数据库授权 | 目标环境、配置和执行范围明确授权 | 等待用户授权，不改变外部状态 |
| 跨层验收 | 契约、运行时、数据库和行为证据完整 | 对应产物所属阶段 |
