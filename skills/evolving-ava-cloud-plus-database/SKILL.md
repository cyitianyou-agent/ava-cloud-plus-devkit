# 演进 AVA Cloud+ 数据库

## 目标

根据已确认的 `datastructures` XML、模块 JAR 或初始化资源，选择 `btulz.transforms` 的真实数据库命令完成结构与数据落地，并验证结果。优先使用工具已有的数据结构编排和数据库类型映射，不自行重写等价 DDL。

本 Skill 位于完整开发流程的构建门禁之后、跨层验收之前。开发期可使用 XML 直接更新测试数据库；从模块制品执行时使用 JAR 路径。

## 开始前建立事实

执行前确认：

1. 输入是单个 `Domain` XML、`ds_*.xml` 目录、模块 JAR、SQL 编排 XML，还是初始化业务数据 JAR。
2. 使用 core JAR 直接传连接参数，还是使用 bobas JAR 从 `app.xml` 读取连接配置。
3. 数据库类型、公司标记、数据库标识、目标环境和适配的 DS 模板。
4. 输入中涉及的表、字段、索引、BO 元数据、SQL 和初始数据。
5. 当前操作是否包含更新元数据、执行任意 SQL、`-force` 或 `-ignore`。

命令参数与选择规则见 [btulz.transforms 数据库命令](references/btulz-database-commands.md)，安全与核验规则见 [执行边界与验证](references/execution-and-validation.md)。

## 选择命令

| 场景 | 命令 |
| --- | --- |
| 开发期根据 XML 创建缺失结构并注册 BO 元数据 | core `ds` |
| 从已构建模块 JAR 执行数据结构及匹配的初始化 SQL | core `dsJar` |
| 执行独立 SQL 编排 XML | core `sql` |
| 根据 `app.xml` 自动取得数据库配置，对 XML 或 JAR 应用结构 | bobas `ds` |
| 从 JAR 导入初始化业务数据 | bobas `init` |

不要用 `sql` 代替可以由 `ds` 表达的标准模型变更。不要为开发期单个 XML 强制先构建 JAR；也不要在验证最终制品时绕过 JAR 内实际打包的资源。

## 关键能力边界

- 经典 DS 模板会创建缺失数据库、表、字段、主键和索引，并注册或更新 BO 元数据。
- 经典 DS 模板通常不会修改已经存在字段的类型、长度、默认值或可空性，也不会删除模型中已移除的表和字段。
- 某些模板会删除明确标识的历史索引，因此即使整体以补缺为主，也必须在执行前阅读所选模板的动作。
- `dsJar` 先应用 JAR 中的数据结构，再执行匹配 `datastructures/sql_*.xml` 的初始化 SQL；它不是只读检查。
- `sql` 执行的是包含数据库编排结构的 XML，不是把任意 `.sql` 文本直接发送给数据库。
- bobas `init -force` 会替换已存在的数据，`-ignore` 会继续处理错误；没有用户明确要求时不使用这些参数。
- 对既有字段类型或长度调整、数据回填、重命名和删除，必须使用项目已有的兼容 SQL 编排或经审阅的新编排；不能声称 `ds` 已经完成。

## 执行流程

1. 读取目标项目 `AGENTS.md`、最终数据结构和相关初始化资源，确认构建产物没有过期。
2. 检查目标数据库类型与 DS 模板、SQL 文件过滤标记、JDBC 驱动相匹配。
3. 在独立临时工作目录运行工具，避免释放模板和生成的编排文件进入模块仓库。
4. 数据库命令会改变外部状态。目标环境和执行范围未由用户明确给出或授权时，只完成命令规划和输入检查，不连接数据库。
5. 执行前列出将使用的输入、命令模式、目标环境标识和潜在高风险动作；不得显示或写入数据库密码。
6. 运行命令后同时检查退出码、日志中的动作级错误和跳过信息。使用 `-ignore` 时，退出码成功不能证明每个动作成功。
7. 按最终 XML 或 JAR 内容执行后置核验，至少检查目标表、字段、主键、索引和 BO 元数据；初始化 SQL 或业务数据还要检查可观察结果。
8. 失败时停止扩大范围，保留错误上下文并判断是模型、模板、连接、权限、兼容 SQL 还是数据问题。

## 完成标准

- 命令模式与输入类型匹配，实际使用的是最终构建产物或已确认 XML。
- 数据库类型、公司标记、目标库和模板一致，没有把示例连接信息当成真实配置。
- 日志不存在未报告的动作级失败。
- XML 声明的缺失结构和 BO 元数据已在目标数据库中核验。
- 既有字段演进、删除、重命名和数据回填没有被 `ds` 的成功退出码掩盖。
- 初始化 SQL 和初始业务数据只在需求涉及时执行，并验证其业务结果。
- 结果报告不包含密码、连接串或客户数据；未获授权或无法连接时明确标记为“未执行”。
